Добавляет Cursor и Hermes в выбор сервисов генерации заголовков тредов и сообщений
коммитов BB. Работает отдельным дополнением через публичный SDK и ACP.

## Требования

BB 0.48 или новее, совместимый SDK ветки 0.6, установленный и авторизованный CLI
Cursor либо Hermes на подключённой машине. Генерация использует лимит аккаунта
агента. Для каждого сервиса можно выбрать свою машину и модель.

## Работа

После настройки выполните встроенную проверку: она подготавливает процесс ACP
и проверяет ответ в пределах тайм-аута BB. Только проверенные настройки помечаются
готовыми. Процесс остаётся в памяти; для каждого текста используется новая сессия.
Голосовой ввод не поддерживается. При ошибке другой аккаунт или провайдер не
подставляется. Инструкция настройки и проверки после обновления находится в README.
